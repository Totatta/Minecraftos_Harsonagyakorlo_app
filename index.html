Új darab

  1. Másold ki a promptot, és küldd el egy MI-nek (pl. Claude) a lefotózott kottával együtt.

GitHub-beállítás (egyszer kell)

A feltöltéssel a darab a tárolóban lévő darabok.txt fájlba kerül, így minden telefonon megjelenik. A kulcs csak ezen a telefonon marad.

  1. GitHub → profilkép → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → ez a tároló.
  3. Permissions → Contents: Read and write. Generate, majd másold ide.
